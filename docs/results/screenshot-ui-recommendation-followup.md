# 스크린샷 후속 수정 — 창 크기·추천·LP 바로가기

## 작업 범위

2026-09-11 사용자 스크린샷 6장을 기준으로 Mini Player 비활성 상태, Now Playing 글자·영상 비율, Open Window 하단 여백과 확대 대응, 추천 결과 부족, LP 바로가기를 보완했다.

## 화면과 조작

- Document PiP API가 없는 환경에서는 Mini Player 메뉴와 화면을 제거한다. 지원되는 환경에서는 기존 기능을 유지한다. 기존 버튼은 현재 곡이 없거나 API가 없으면 비활성화되는 구조였다.
- Now Playing 제목·채널·컨트롤 글자와 정보 영역을 줄여 영상 영역을 확보한다.
- 별도 창의 고정 최대 너비를 해제하고 최소 레이아웃을 유지하면서 창 확대에 맞춰 본체·LCD를 확장한다.
- LP를 접근 가능한 버튼으로 바꾸고 AI Picks 이동 후 현재 곡 검색을 연결한다. 기존 OpenAI 연결 조건과 중복 요청 방지를 사용한다.
- 명시적인 `[hidden]` 스타일로 오류·완료 상태에서 진행 표시가 남지 않게 한다.

## 추천 검색과 검증

- 후보 풀 상한을 10곡에서 15곡으로 늘리고 가능한 경우 5곡을 선택하도록 요청한다.
- 방송·유통 채널명을 실제 아티스트로 단정하지 않고 무대 영상의 원곡을 식별하도록 프롬프트를 보완한다.
- 결과가 부족하면 예비 후보를 5개씩 검증해 서로 다른 5곡을 목표로 보충한다. 기존 Playlist 영상 등 제외 대상은 개수 집계 전에 제거한다.
- 메타데이터 이름의 정규화 길이가 3자 미만이면 무조건 탈락하던 조건을 수정한다. 짧은 이름은 정확한 토큰 일치로 확인하며 `Go`와 `Golden` 같은 부분 문자열 오탐을 막는다.
- `Official Video` 같은 일반 수식어만 일치해서 다른 곡이 통과하지 않게 한다. 아티스트와 곡명 검증은 유지한다.
- 후보가 소진되거나 추가 검색이 실패하면 검증된 부분 결과를 보존한다. 외부 응답과 관계없이 항상 5곡이 나온다고 보장하지 않는다.

스크린샷 당시 원본 응답은 없어 정확한 실패 원인은 확정하지 않았다. 짧은 이름 제외 결함은 코드와 모의 응답으로 확인한 문제다.

구현 중 관련 테스트: 추천·Resolver 17개, 화면 이동·Player 8개 통과. 실제 OpenAI·YouTube 요청과 추천 품질은 미검증이다. 최종 통합·브라우저 결과는 아래에 별도로 기록한다.
