# SIMILAR VIBES · 기준 곡 선택과 조작부 후속 결과

2026-09-12 사용자 요청 반영.

- SIMILAR VIBES 내부에서 API 키 연결과 Playlist 기준 곡 선택을 제공한다. 연결 성공 후 입력을 지우고 GET PICKS를 표시한다. 기준 곡 선택은 현재 재생을 바꾸지 않는다.
- 기준 곡은 ID로 요청하고 background가 저장된 Playlist에서 확인한다. 검색 중 선택을 잠그고, 기준 변경 시 이전 결과를 비운다. LP를 열기만 해서는 추천을 요청하지 않는다.
- 후보 조사·최종 선정은 원래 발매 연도/시대, 장르, 언어를 우선한다. 다음으로 분위기·보컬, 이후 에너지·그루브·템포감·악기·프로덕션을 고려한다. 임의 연도 범위는 두지 않는다.
- 공식 MV 검색 원칙을 유지하고 명시적 리액션·해설 제목을 검증 단계에서 제외한다. 모든 영상의 공식 출처를 이 검사만으로 보장하지 않는다.
- 중복 정보만 보여주던 i 버튼을 제거했다. 재생 화면의 Playlist는 곡 선택 후 재생을 이어가며 자동으로 닫힌다.
- 운영체제 기본 select 대신 LCD 내부의 제한된 높이 목록을 사용한다. 긴 곡명은 줄임표로 표시하며 전체 접근성 이름과 title을 제공한다. 방향키, Home/End, 선택, Escape와 물리 A/B를 지원한다.
- Home 항목 간격을 넓히고 LCD 제목을 HOME으로 바꿨다. 방향키와 A/B에는 측면 두께·하이라이트·눌림 그림자를 적용했다.
- MINI PLAYER 메뉴 제거, 실제 재생 상태의 POWER 표시등, 상단 안내 문구 삭제를 유지한다.

## 같은 아티스트 편중 후속 수정

후보 조사·후보 추출·최종 선정에 공통 아티스트 규칙을 추가했다. 발매 연도·장르·언어 우선순위는 유지하며 기준 곡과 다른 아티스트를 우선한다. 후보 풀과 최종 목록 모두 아티스트당 최대 1곡을 요청하고, 한글/영문 별칭과 표기 차이를 같은 아티스트로 다룬다. 후보 부족 시 동일 가수 곡으로 채우지 않으며, 이를 허용하도록 선택 JSON의 최소 개수 강제를 제거했다. 빈 결과는 기존 NO_CANDIDATES 처리 경로를 따른다. 아티스트 의미 판별은 프롬프트 지시이며 실제 추천 품질은 API 호출로 검증하지 않았다.
