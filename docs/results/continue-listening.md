# 이어 듣기 — LP 슬라이드와 자연스러운 음악 흐름

2026-09-12 사용자 요청에 따라 AI Picks의 표시 이름을 ‘이어 듣기’로 바꾸고 추천의 목적을 현재 곡의 느낌을 유지하는 다음 곡 순서로 변경했다.

## 동작

- Now Playing에서 LP를 누르면 재생을 유지한 채 추천 패널이 아래에서 올라온다. B·닫기·LP로 내릴 수 있다.
- Playlist 슬라이드와 하나씩 열리며 메뉴의 이어 듣기와 동일한 추천 DOM·상태를 공유한다.
- 같은 기준 곡으로 다시 열면 기존 결과를 재사용한다. ‘다시 추천’은 새 검색을 실행한다.
- 패널에서 A 또는 추가 버튼으로 곡을 Playlist에 넣어도 현재 곡은 유지된다. 요청 당시 기준 곡을 표시한다.
- API Key 연결이 필요하면 연결 화면을 거친 뒤 추천 슬라이드로 돌아온다.

## 추천 기준

현재 곡을 시작점으로 Playlist 순서와 곡 위치를 전달한다. 분위기·에너지·그루브·템포 느낌·악기·보컬·프로덕션을 우선하고 발매 시기·언어·장르명은 보조 기준으로 둔다. 첫 추천은 현재 곡 다음에, 이후 추천은 앞선 추천곡 다음에 자연스럽게 이어지도록 선택한다.

후보는 최대 15곡, 추천 목표는 5–8곡이다. 선택 스키마·파서·Runtime 검증의 상한을 8로 통일했다. 추가 영상 검색이 늦게 성공해도 최종 목록은 선택 순서로 정렬한다. 곡을 만들거나 검증을 생략해 개수를 채우지 않으며, 5곡 미만이면 확보한 결과와 안내를 표시한다.
