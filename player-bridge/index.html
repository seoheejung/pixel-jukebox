    03 / AI WORKFLOW

    추천보다 중요한 건,
    검증된 다음 곡입니다.

    모델이 만든 링크를 믿는 대신, 조사된 후보 안에서 흐름을 설계하고 실제 YouTube Metadata까지 다시 확인합니다.

    1. 01CONTEXT

      현재 곡, Playlist, 최근 추천으로 중복과 흐름을 파악

    2. 02DISCOVERY

      Web Search로 분위기와 시대감이 이어지는 후보 탐색

    3. 03EXTRACTION

      근거가 있는 Artist와 Track만 구조화해 추출

    4. 04SELECTION

      검증 후보 ID만으로 다음 재생 순서를 구성

    5. 05RESOLVER

      실제 YouTube 출처를 찾고 허용 영상 유형 확인

    6. 06VALIDATION

      oEmbed Metadata가 Artist와 곡에 일치하는지 최종 검증

    05 / RUN THE FULL EXTENSION

    전체 기능은 Chrome에서.

    Web Demo가 공식 제출 경로입니다. 아래 설치는 실제 YouTube Player와 OpenAI 연동을 포함한 전체 Extension을 추가로 확인하려는 사용자를 위한 방법입니다.

    REPOSITORY ↗
    PLAYER BRIDGE · EXTENSION ONLY https://seoheejung.github.io/pixel-jukebox/player.html Extension이 재생 정보를 전달할 때 사용하는 연결 경로이며, 단독 실행 화면이 아닙니다.
    1. 01

      Node.js 22.12+ 준비 후 Repository clone

    2. 02

      npm ci

    3. 03

      bridge.config.local.json에 Player Bridge URL 설정

    4. 04

      npm run build

    5. 05

      Chrome 확장 프로그램 페이지에서 dist/ Load unpacked

    6. 06

      KEEP THIS VIBE 사용 시 Settings의 OpenAI API Key 입력 후 CONNECT
